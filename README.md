# Projeto Docker na AWS EC2 

Repositório dedicado ao estudo e empacotamento de uma aplicação web em Python utilizando Docker, com o objetivo de realizar o deploy em uma instância EC2 da AWS.

## Tecnologias Utilizadas

* **Linguagem:** Python 3.10
* **Containerização:** Docker
* **Provedor Cloud:** AWS (EC2)
* **Versionamento:** Git / GitHub

    └── app.py          # Servidor web simples em Python
